🖥️ FCFS Scheduling Algorithm in C  
------------------  
Project Overview  
----------  
This project implements the First Come First Serve (FCFS) CPU scheduling algorithm using the C programming language.

FCFS is one of the simplest scheduling algorithms in Operating Systems where processes are executed in the order they arrive in the ready queue.    
  
Concept  
--------
In FCFS scheduling:

The process that arrives first gets executed first.

It is a non-preemptive scheduling algorithm.

Once a process starts executing, it runs until completion.

Waiting time and turnaround time are calculated based on arrival order.  
  
Features  
--------
Accepts number of processes from user

Takes burst time for each process

Calculates:

  * Waiting Time
  
  * Turnaround Time

  * Average Waiting Time

  * Average Turnaround Time

  Displays results in a formatted table  

Technologies Used
-------

C Programming Language

Standard I/O Library (stdio.h)
